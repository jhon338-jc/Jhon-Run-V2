# 🏃 JHON RUN - Endless Runner Game

> Game lari tanpa henti dengan sistem koin, power-up efek, dan mode admin.  
> **Dibuat oleh JHON338** | Versi 2.5

---

## 📱 Deskripsi Singkat

**JHON RUN** adalah game endless runner bergaya retro-comic yang dimainkan di browser (mobile/desktop).  
Karakter berlari mengumpulkan koin, menghindari musuh (batu bata merah), dan melompati platform.  
Terdapat **power-up "Efek"** yang membuat karakter super cepat dan tembus musuh.

| Tombol | Fungsi |

### Fitur Utama:
- 🪙 **Koin** - Dikumpulkan untuk membeli efek di SHOP
- ⚡ **Efek** - Beli di SHOP (5 koin), aktifkan saat game berjalan
- 🔑 **Mode Admin** - Ketik `JHON338` di SETTING → koin & efek unlimited
- 🎵 **Suara** - Bisa ON/OFF di SETTING
